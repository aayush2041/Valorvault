# ValorVault

Premium third-party digital gaming marketplace.

## Included
- Responsive storefront UI
- Product discovery and filters
- Cart and checkout prototype
- Manual payment UX for UPI, QR and bank transfer
- UTR + screenshot submission workflow
- Admin verification architecture
- Delivery/email architecture
- Security notes for payment proofs and digital inventory

## Important
Do not commit real payment, SMTP, database, storage, session, or encryption secrets. Configure them as server-side environment variables.
